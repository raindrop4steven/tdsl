# DSL 编译器的设计与实现

> 面向本科生的编译器教材，以自研低代码 DSL（TDSL）为贯穿案例。
> 不是编译原理的泛泛而谈，而是一个**真实可运行的编译器**的完整设计推导。
>
> 配套代码：`packages/core` / `parser` / `typecheck` / `codegen-java` / `codegen-react`
> 验证命令：`npm test`（272 单测）/ `npm run slice`（端到端构建）
