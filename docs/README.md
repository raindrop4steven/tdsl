# 项目文档

基于网易 CodeWave NASL 的调研与自研低代码 DSL（TDSL）设计文档。

## 目录导航
- `00_参考资料/` — 网易 NASL 调研（领域覆盖、三投影、类型、命名空间、继承/组合、SDK）+ 设计原理调研汇报
- `10_需求设计/` — 目标、核心路线、关键决策、需求清单
- `20_系统设计/` — 分层架构、模块划分、数据流、LLM 管线
- `30_详细设计/` — 类型定义、表达式语言、生成器映射、算法
- `40_编码/` — 编码约定（仓库代码）
- `50_测试用例/` — 单元测试
- `60_集成测试/` — 端到端集成测试
- `70_教程/` — 编译器入门教程（P0 五包逐包讲解）
- `99_成果物/` — 交付物索引

## 阅读顺序
1. `00_参考资料/NASL调研.md`
2. `10_需求设计/需求设计.md`
3. `20_系统设计/系统设计.md`
