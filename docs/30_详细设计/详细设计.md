## 1. 核心包 `core` —— Typed AST 与对象模型

### 1.1 节点基类

```ts
interface BaseNode {
  kind: string;                 // 类型标签：由具体判别联合字面量推导，而非手写字符串
  id: string;                   // 全局唯一 uuid
  annotations?: Annotation[];   // 可选语义性注解 @xxx
}

// 语义性注解（区别于编辑器 UI 元信息）
interface Annotation {
  kind: 'Annotation';
  name: string;                 // 如 'datasource' | 'export' | 'label'
  args?: Record<string, unknown>;
}
```

### 1.2 判别联合（核心领域节点）

```ts
type AnyNode =
  | AppNode
  | DataSourceNode | DataSourceConfigNode
  | EntityNode | EntityPropertyNode | EntityIndexNode
  | EnumNode | EnumItemNode
  | StructureNode | StructurePropertyNode | TypeParamNode
  | LogicNode | ParamNode | ReturnNode | VariableNode
  | InterfaceNode | EndpointNode
  | ViewNode | ViewElementNode | PageNode
  | ProcessNode | ProcessNode_ | ApprovalPolicyNode;   // 命名仅示意
```

各节点示意：

```ts
interface AppNode extends BaseNode {
  kind: 'App';
  name: string;
  datasources: DataSourceNode[];
  structures: StructureNode[];
  enums: EnumNode[];
  logics: LogicNode[];
  interfaces: InterfaceNode[];
  views: ViewNode[];
  processes: ProcessNode[];
}

interface EntityNode extends BaseNode {
  kind: 'Entity';
  name: string;
  source?: DataSourceRef;          // 符号引用（nodePath）
  table?: string;
  properties: EntityPropertyNode[];
  indexes: EntityIndexNode[];
}

interface EntityPropertyNode extends BaseNode {
  kind: 'EntityProperty';
  name: string;
  label?: string;
  type: TypeRef;                   // 符号化类型
  db?: DatabaseTypeRef;            // 可选：数据库存储类型/精度
  defaultValue?: DefaultValueNode;
  primary?: boolean;
  unique?: boolean;
  nullable?: boolean;
}
```

## 2. 类型系统 `TypeRef`

```ts
type BuiltinType =
  | 'Boolean' | 'Integer' | 'Decimal' | 'String'
  | 'Date' | 'Time' | 'DateTime';

type TypeRef =
  | { kind: 'primitive'; builtin: BuiltinType }
  | { kind: 'reference'; path: string }        // 指向某节点 nodePath
  | { kind: 'generic';  name: 'List' | 'Map' | 'Page'; args: TypeRef[] }
  | { kind: 'db';       builtin: string; args?: Record<string, unknown> }; // decimal(p) 等

interface DefaultValueNode extends BaseNode {
  kind: 'DefaultValue';
  expr: Expr;                       // 或字面量
}
```

内置类型层级（供 typechecker 使用）：
```
Any(BaseType)  ← 所有类型超类型
  ├ Boolean ├ Integer ├ Decimal ├ String ├ Date ├ Time ├ DateTime
  └ List<T> / 引用结构 / 枚举 ...
Null  ← 所有类型子类型（含字面量 null）
隐式转换：Integer → Decimal（单向）；子类型 → 超类型。
```

## 3. 小表达式语言 `Expr` / `Statement`

> **两层设计（关键澄清）**：
> - **书写层 = TS 语法子集**：LLM 用其本能语法写（`if`/`for`/`return`/`new`/`a.b.c()`/字面量）。
> - **解析层 = 编译为下方的自研类型化 AST**：`Expr`/`Statement` 是**语法（书写面）被 parse 之后的语义节点**，
>   即"书写的 TS 子集 → 我们的 AST"。语法不自创，大模型不会不认识；
>   语义是可编译、可检查、可跨端映射到 React/Java 的。

### 3.1 表达式

```ts
type Expr =
  | { kind: 'Ident'; name: string }                    // a
  | { kind: 'Member'; obj: Expr; prop: string }        // a.b
  | { kind: 'Index'; obj: Expr; index: Expr }          // a[i]
  | { kind: 'Call';  callee: Expr; args: Expr[] }      // f(x)
  | { kind: 'New';   type: TypeRef; args: Expr[] }     // new Order(...)
  | { kind: 'NewList'; elem: TypeRef; items?: Expr[] }
  | { kind: 'Literal' }  // 见下 LiteralExpr
  | {
      kind: 'Binary';
      operator: '+'|'-'|'*'|'/'|'%'|'==='|'!=='|'<'|'<='|'>'|'>='|'&&'|'||';
      left: Expr; right: Expr;
    }
  | { kind: 'Unary'; operator: '!'|'-'; operand: Expr }
  | { kind: 'Group'; expr: Expr };

type LiteralExpr =
  | { kind: 'Bool';   value: boolean }
  | { kind: 'Numeric'; value: number }
  | { kind: 'String';  value: string }
  | { kind: 'Null' }
  | { kind: 'Date';   value: string }
  | { kind: 'Time';   value: string }
  | { kind: 'DateTime'; value: string };
```

### 3.2 语句

```ts
type Statement =
  | { kind: 'VarDecl'; name: string; type?: TypeRef; init?: Expr }
  | { kind: 'Assign';  target: Expr; value: Expr }      // target 一般为 Member/Ident/Index
  | { kind: 'Return';  value?: Expr }
  | { kind: 'If';      cond: Expr; then: Statement[]; else?: Statement[] }
  | { kind: 'ForEach'; item: string; container: Expr; body: Statement[] }
  | { kind: 'While';   cond: Expr; body: Statement[] }
  | { kind: 'Break' } | { kind: 'Continue' }
  | { kind: 'CallStmt'; call: Expr }
  | { kind: 'Block'; body: Statement[] };
```

### 3.3 逻辑节点

```ts
interface LogicNode extends BaseNode {
  kind: 'Logic';
  name: string;
  abstract?: boolean;
  params: ParamNode[];
  returns: ReturnNode[];            // 支持多返回
  body: Statement[];                // 小语言语句序列
  typeParams?: TypeParamNode[];
}

interface ParamNode extends BaseNode {
  kind: 'Param';
  name: string;
  type: TypeRef;
  defaultValue?: DefaultValueNode;
}

interface ReturnNode extends BaseNode {
  kind: 'Return';
  name?: string;                    // 多返回值命名
  type: TypeRef;
}
```

## 4. 接口与页面（视图）

```ts
interface InterfaceNode extends BaseNode {
  kind: 'Interface';
  name: string;
  basePath?: string;                // 如 /api/order
  endpoints: EndpointNode[];
}

interface EndpointNode extends BaseNode {
  kind: 'Endpoint';
  name: string;
  path: string;                     // 相对 basePath
  method: 'GET'|'POST'|'PUT'|'DELETE'|'PATCH';
  request?: StructureNode | TypeRef;
  response?: TypeRef;
  logicRef?: string;                // 绑定到某个 Logic 的 nodePath
}

interface ViewNode extends BaseNode {
  kind: 'View';
  name: string;
  kind_: 'page' | 'dialog' | 'block';   // 避免与 kind 重名，命名仅示意
  elements: ViewElementNode[];
  dataSource?: BindingNode[];       // useQuery 数据绑定
}

interface ViewElementNode extends BaseNode {
  kind: 'ViewElement';
  type: string;                     // 'table' | 'input' | 'button' ...
  props: Record<string, Expr | string>;
  bindings?: BindingNode[];
  children?: ViewElementNode[];
}

interface BindingNode extends BaseNode {
  kind: 'Binding';
  name: string;                     // 数据/方法名
  target: string;                   // 引用的 logic/query nodePath
}
```

## 5. parser 包 —— TDSL(TS投影) → AST

- 手写递归下降（或 PEG/nearley）解析 `TDSL` 文本。
- 产出 Typed AST；语法错误带行号/列号与 nodePath。
- 提供 `jsonToTyped` / `typedToJson` 与 AST 无损互转（round-trip 测试保证）。

### 5.1 TDSL 书写投影示例（给 LLM 的主入口形态）

```ts
// ---- entities.tdsl ----
@datasource('defaultDS')
entity Product {
  id: Integer @pk;
  name: String;
  price: Decimal(10,2);
}

// ---- structure ----
struct ProductOrder {
  product: Product;       // 引用实体（符号 -> nodePath）
  count: Integer;
}

// ---- logic ---- （backend 方法，书写层为 TS 语法子集，include 简述）
@export
logic createOrder(input: CreateOrderInput): Order {
  order := new Order(input);
  order.save();
  return order;
}

// ---- view ----
page ProductList {
  <table dataSource={useQuery('Product.findList')}>
    <column field="name" />
  </table>
}
```

注意：`@pk`/`Decimal(10,2)`/`:=`/`useQuery`/JSX 均为书写层语法糖，parser 归一为 Typed AST 的 `annotations`/`TypeRef`/`Assign`/`Binding`。

## 6. typecheck 包（较重：完整类型检查器）

> 定位：接近真实编译器的类型检查层，保证编译期"语义可信" before 生成代码。

### 6.1 阶段划分
1. **bind（符号绑定）**：构建 **SymbolTable**（nodePath → 对象），`resolve(app, path)` 查表，
   找不到报"悬空引用"；成员访问沿类型结构下钻。
2. **infer（类型推导）**：为表达式做**局部推导**（字面量/构造/调用/成员返回类型），支持函数返回类型推断。
3. **check（类型检查）**：`assignable(from, to, ctx)` 校验赋值/传参/返回兼容性，
   `unify` 处理泛型 `List<T>` 等调用点推断（unification）。
4. **report（诊断）**：输出 `Diagnostic{path, line?, col?, message, severity}`。

### 6.2 关键能力
- **子类型/隐式转换**：`Integer→Decimal`（单向）；子类型→超类型（`Any` 为顶、`Null` 为底）。
- **泛型**：`List<T>`、`Map<K,V>`、`Page<T>` 的参数化与实例化检查。
- **成员/方法解析**：`a.b`、`a.b()` 沿结构/实体/接口类型解析，并核对参数类型。
- **可达性与返回**：方法末尾返回值类型须匹配 `Return` 声明。

### 6.3 接口

```ts
interface Diagnostic { path: string; line?: number; col?: number; message: string; severity: 'error'|'warning' }
function check(app: AppNode): { ok: boolean; diagnostics: Diagnostic[] };
```

## 7. codegen 生成器

### 7.1 Java（Spring Boot + JPA）

| AST 节点 | 生成 |
|---------|------|
| `Entity` | JPA `@Entity` + `@Table` + 字段(`@Column`/`@Id`) |
| `EntityProperty` | 字段 + 类型映射（`Integer->long` `Decimal->BigDecimal` `Date->LocalDate` `DateTime->ZonedDateTime`）+ `@NotNull` 等 |
| `Logic` | Service 方法与 `@Transactional` |
| `Endpoint` | `@RestController`/`@RequestMapping` 方法映射到 Logic |
| `Expr` 平台翻译 | `===`→`equals`、`&&`→`and`、`List`→`java.util.List`、`Decimal` 精度处理 |

### 7.2 React（组件 + hooks + axios）

| AST 节点 | 生成 |
|---------|------|
| `View/page` | React 函数组件（TSX） |
| `ViewElement` | 对应组件（table/input/button 等） |
| `Endpoint/Logic` | axios/fetch 封装 + `useQuery`/`useMutation` hooks |
| `Binding` | `dataSource={query.data}` 绑定 |
| `Expr` 翻译 | 多数 1:1（TS 侧）；`Decimal`→`number`，日期→ISO 字符串 |

### 7.3 生成器骨架

```ts
function genExpr(e: Expr, ctx: TargetCtx): string {
  switch (e.kind) {
    case 'Ident':   return e.name;
    case 'Member':  return `${genExpr(e.obj, ctx)}.${e.prop}`;
    case 'Binary':  return `(${genExpr(e.left, ctx)} ${ctx.op(e.operator)} ${genExpr(e.right, ctx)})`;
    // ...
    default: { const _: never = e; throw new Error(`unknown expr ${(e as Expr).kind}`); }
  }
}
```

每个生成器接受 `TargetCtx`（算符映射、类型映射、命名规范）以做平台差异。

## 8. llm 包

- **prompt pack 生成器**：由 `core` 的节点类型 + 示例 TDSL 合成给 LLM 的说明。
- **双通道输入**：TDSL 文本 / JSON AST。
- **校验修复**：zod schema（`schema` 包）校验 LLM 输出；失败时反馈错误并让 LLM 重试（或结构化修复）。
- `SchemaPack`：把判别联合转成 JSON Schema / 示例矩阵，供 LLM 直接消费。

---

## 9. schema 包

- 用 zod/valibot 为每个节点定义运行时校验 schema（也可 `ts-to-zod` 从类型生成）。
- `serialize(node): JsonNode`（排除 `parent`/运行时字段）、`deserialize(json): AppNode`。
- round-trip 测试：`deserialize(serialize(x)) === x`（结构等价）。

## 10. CLI 与 Playground（P1+）

```bash
dsl parse    in.tdsl -o ast.json        # TDSL → AST（JSON 视图）
dsl generate in.tdsl --target react --out src/
dsl generate in.tdsl --target java  --out java/
dsl check    in.tdsl                    # 类型检查 + 引用绑定
dsl build    in.tdsl -o dist/           # 校验 + 双端生成
dsl fmt      in.tdsl                    # 归一化书写投影文本
```

Playground：网页端在编辑器输入 TDSL，实时显示 JSON AST 与生成的 React/Java，双向互转保温定。
