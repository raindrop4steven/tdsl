# 00 总览：流水线与核心哲学

> 配套代码：`examples/todo-app/scripts/slice.ts`（闭环驱动入口）

## 1. 整条流水线

```
todo.tdsl ──parse──▶ Typed AST ──typecheck──▶ { ok, diagnostics }
   （文本）    @tdsl/parser      @tdsl/core      @tdsl/typecheck
                                              │ ok
                              ┌───────────────┴───────────────┐
                              ▼                               ▼
                    @tdsl/codegen-java                 @tdsl/codegen-react
                    Spring Boot 工程                     Vite + React 工程
                    mvn compile ✓                       vite build ✓
```

包依赖方向（从底到顶）：`core` ← `parser` / `typecheck` ← `codegen-java` / `codegen-react` ← `todo-app`。

## 2. 两种角色

五个包分两类职责：

| 角色 | 包 | 干什么 |
|------|-----|--------|
| **进**（文本 → 可信 AST） | `core` / `parser` / `typecheck` | 把 LLM/人写的 TDSL 炼成干净、类型化、检查过的语义树 |
| **出**（AST → 可编译产物） | `codegen-java` / `codegen-react` | 把同一棵 AST 翻译成双端工程，语义一致 |

## 3. 三个咬合各包的约定

1. **判别联合 + `never` 穷尽** —— 每个节点用 `kind` 字段做类型标签，TS 靠它收窄；生成器 switch 完所有 kind 后放 `const _never: never = x`，以后新增节点类型但没更新生成器，TS 编译直接报错。
2. **nodePath 字符串引用** —— 跨节点引用（如 `List<Todo>` 里的 `Todo`）不存对象指针，存字符串路径 `app.datasources.defaultDS.entities.Todo`，编译期 `resolve()` 绑定，悬空引用被编译器捕获。
3. **纯函数 / 确定性输出** —— codegen 返回 `GeneratedFile[]`（path + content）不碰磁盘；同 AST 必得同输出，可快照测试、可 diff 回归。

## 4. 两个关键产品类型

```ts
interface GeneratedFile { path: string; content: string; }   // codegen 统一产出

interface Diagnostic {
  path: string;        // 出错节点 nodePath（可编程寻址，不是文本报错）
  line?: number;
  col?: number;
  message: string;
  severity: 'error' | 'warning';
}
```

`Diagnostic.path` 必填是核心：调用方拿到 path 就能 `resolve` 回出错节点继续处理（编辑器高亮、LLM 修复管线都能用）。
