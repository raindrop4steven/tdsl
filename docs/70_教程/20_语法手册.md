# TDSL 语法手册

> 定位：**面向书写者**（人 + LLM）的语言手册——完整语法、语义、每条可运行片段。
> 所有片段来自 `examples/`（todo / jxc / fastjson-demo）与单测，均可编译（`npm run dsl -- check` 验证）。
> 配套：LLM 用的 400 token 速查表在 `packages/llm/src/cheatsheet.ts`（只写形态，语义以本手册为准）。

## 0. 一分钟了解 TDSL

TS 风格的低代码 DSL：**书写面用 TS 词法**（`function/const/for-of`），**骨架声明用领域关键词**（`entity/page/interface`）。
不是严格 TypeScript 子集——`@pk`、`Order.where(...)` 这些 TS 没有。内置类型是领域类型（`Integer/Decimal`，**没有** `number/string`）。
legacy 词法（`:=` / `for-in` / `logic`）已从 parser 删除，写入即报语法错误。

一个文件长这样（完整可编译，`examples/fastjson-demo/demo.tdsl`）：

```
dependency java "com.alibaba:fastjson2:2.0.58";   // 可选：依赖声明

@datasource('defaultDS')                          // 可选：数据源声明/切换

@export
function toJson(o: Object): String {              // 业务逻辑（TS 词法）
  return JSON.toJSONString(o);
}

interface FastjsonApi {                           // REST 契约
  POST '/api/to-json' -> toJson
}

page DemoHome {                                   // 页面（JSX 子集）
  <table dataSource={useQuery('listDemo')}>
    <column field="goodsName" title="示例" />
  </table>
}
```

## 1. 顶层声明

### 1.1 依赖声明 `dependency`（dev/32）

```
dependency java "com.alibaba:fastjson2:2.0.58" import { JSON, JSONObject };   // import 列表：类以裸名进有效目录
dependency java "com.fasterxml:jackson:2.17.0" as jackson import { JSON };    // as ns = jar 命名空间（撞名消解），调用写 jackson.JSON
dependency npm "antd@^5.21.0";                             // 纯依赖（只进 package.json）
dependency npm "echarts-for-react" import ECharts;         // 默认导出组件
dependency npm "@ant-design/charts" import { Pie, Bar };   // 具名导出组件（一包多组件）
```

语义：声明工程依赖 → Java 端进 `pom.xml`、React 端进 `package.json`。**用第三方库必须先声明**（D-dep-1 error）；
声明的 jar 需要有对应扫描产物放工程 `libs/*.json`（D-dep-2 warning；版本漂移 D-dep-3 warning）。

**import 段（dev/34 统一形态）**：
- `import X`（单名）= 默认导入；`import { A, B as C }`（花括号）= 具名导入，`as` 改名——与 JS import 语义字面一致
- java：import 列表声明哪些产物类以裸名可用；两个 jar 都 import 同名类才撞（D-dep-4），撞了给其中一个加 `as ns`，调用写 `ns.JSON`
- npm：import 声明页面可用的组件名；未显式 import 的声明只进 package.json

### 1.2 数据源 `@datasource`

```
@datasource('erp')
entity Order { ... }          // 归入 erp

@datasource('crm')
entity Customer { ... }       // 归入 crm
```

独立顶层语句（非实体修饰符）：声明/切换当前数据源，此后 `entity` 归入它直到下一次切换。
**命名空间规则（M1）**：实体短名归数据源作用域——跨源同名实体（`erp.Order` / `crm.Order`）可共存；
引用时短名在本数据源内唯一即可命中，跨源歧义必须写限定名 `erp.Order`（歧义不写限定名直接报错）。

### 1.3 实体 `entity`

```
@datasource('defaultDS')
entity Order {
  id: Integer @pk;
  title: String;
  total: Decimal @nullable;
  status: OrderStatus;        // 枚举类型直接引用
  createdAt: DateTime;
}
```

属性注解：`@pk`（主键）/ `@nullable` / `@unique`。
内置标量类型：`Integer Decimal String Boolean Date Time DateTime`（**没有** number/string/Date——D4 口径）。
实体生成 JPA `@Entity` + Repository；`@pk` 字段是 `Order.get(id)` 的依据。

### 1.4 结构 `struct` 与枚举 `enum`

```
struct OrderInput {                 // DTO / 嵌套结构（无表）
  title: String;
  items: List<OrderItemInput>;      // 泛型嵌套
}

enum OrderStatus { DRAFT, SUBMITTED }        // Java enum + 前端 Select 选项
enum DocStatus { DRAFT('暂存'), SUBMITTED('已提交') }   // G1：KEY('中文') 显示标签
```

### 1.5 外部服务 `service`（dubbo / http —— 外部系统对接）

```
@service(kind = 'dubbo', group = 'user-center', version = '1.0.0')
service UserSvc {
  getUser(id: Integer): User;
}

@service(kind = 'http', baseUrl = 'http://erp-center')
service ErpApi {
  GET '/api/orders/{id}' -> getOrder(id: Integer): Order;    // http 必须带 METHOD + path
}
```

function 内像本地方法调用（`userSvc.getUser(id)`）；生成端分别是 `@DubboReference` / `@FeignClient`。

**边界（dev/33）**：`service` 只管**外部系统对接**——dubbo 引用别人家运行中的 RPC 服务，http 声明别人家 REST API 契约。
**本地 jar 里的类不用 service**：`dependency java` 声明坐标 + libs 产物后 function 直调（一等公民，见 §5）。`kind='bean'` 已删除。

### 1.6 三方组件（npm 一等公民，无注册层）

```
dependency npm "echarts-for-react" import ECharts;               // 默认导出
dependency npm "@ant-design/charts" import { Pie, Bar, Line };   // 具名导出（一包多组件）

page Dashboard {
  <ECharts dataSource={useQuery('orderStats')} />
  <Pie data={...} angleField="value" />            // 直接用，import 由声明生成
}
```

- 页面直接写三方组件标签，**不再有 component 注册层**（dev/33 删除）
- import 解析（dev/34）：`import X` → `import X from 'pkg'`；`import { A, B }` → 同包聚合 `import { A, B } from 'pkg'`；无 import 的声明只进 package.json
- 未匹配到声明 → typecheck 报错并提示补 `dependency npm`

## 2. 业务逻辑 `function`（TS 词法面）

```
@export
function createOrder(input: OrderInput): Order {
  if (input.items.count === 0) { return null; }

  const order = new Order();          // const 声明（可标类型：const n: Integer = 0）
  order.total = 0;
  order.save();                       // 实例方法；写操作自动 @Transactional

  for (const it of input.items) {     // for-of 遍历
    it.save();
  }
  return order;
}
```

| 形态 | 语义 |
|------|------|
| `const x = expr` / `const x: T = expr` | 变量声明（唯一形态；`:=` 为废弃 legacy，**禁止书写**） |
| `if (cond) { ... } else { ... }` | 条件；**无三元 `?:`** |
| `for (const x of xs)` | 遍历 List（唯一形态；`for-in` 键遍历为废弃 legacy，**禁止书写**） |
| `throw '仅暂存单可提交';` | 抛业务异常 → HTTP 400 `{code:'GENERIC', message}`（advice 统一映 4xx，前端 `hooks.error` 展示） |
| `===` / `!==` | 相等判断；**无 `==`** |
| `&&` / `\|\|` / `!` | 逻辑运算 |
| `+ - * /` | 算术；Decimal 自动 BigDecimal 包装 |

**书写口径（P11 收尾）**：TS 面是唯一书写口径——`function`、`const =`、`for-of`。legacy 词法（`logic`/`:=`/`for-in`）已物理删除（报错消息自带废弃口径），**新代码/LLM 输出一律 TS 面**，示例矩阵已全部 TS 化。

**禁止清单**（LLM 最易犯"把 TDSL 写成 TS"）：三元、模板字符串、`==`、箭头函数、`class`、泛型约束、`:=`、`for-in`、`logic`。

### 2.1 实体方法

```
Order.get(id)                        // 静态：主键查
Order.all                            // 静态：全表（ForEach 容器/查询链起点）
entity.save() / entity.delete()      // 实例：持久化（写操作自动事务）
```

### 2.2 查询语言（M2）

```
Order.where(total > 0)                              // 条件运算符: = >= <= > < like in（= 是"等于"！）
Order.where(billNo like '%x%', status = status)     // 逗号分隔 = AND
Order.where(a > 0 && b < 10, c = 1)                 // 条件内 && / || 递归组合
Order.where(...).orderBy(total desc)                // 链式排序（方向 asc|desc）
Order.where(...).limit(10)                          // 限条 → findTop10
Order.where(...).page(1, 20)                        // 分页 → Page<T>
Order.aggregate(sum(total))                         // 聚合: sum/avg/max/min/count
Order.aggregate(sum(total)).groupBy(customer)       // 分组 → List<Map<Object>>
```

条件字段必须是实体属性（typecheck 校验），运算符在白名单内。

### 2.3 List 方法（FFI 内核）

```
xs.add(x)      // 追加
xs.count       // 元素数（.size 同义）
xs.get(i)      // 按下标取
xs.contains(x) // 包含判断
xs.isEmpty     // 空判断
```

字符串方法同理：`trim / toUpperCase / toLowerCase / contains / startsWith / endsWith / replace / substring / indexOf / isEmpty / length`。
第三方库成员（如 fastjson2 的 `JSON.toJSONString`）须 `dependency` 声明 + libs 产物收录后可用。

## 3. 接口 `interface`

```
interface OrderApi {
  GET '/api/orders' -> listOrders                  // -> 绑定 function 名
  GET '/api/orders/{id}' -> getOrderDetail         // {id} 路径参数
  POST '/api/orders' -> createOrder
}
```

- 生成 Java `@RestController` + 前端 `api.ts` fetch 函数
- **绑定函数必须被 interface 端点暴露**——页面 binding 引用了未暴露的函数，typecheck 报错（前端会白屏的实战教训）

## 4. 页面 `page` / 弹窗 `dialog`（M4）

```
@title('销货单列表') @menu('销售管理')            // 中文显示名 + 菜单分组（折叠菜单）
page SalesBillList {
  <input field="billNo" label="销货单号" />       // 查询条件区
  <table dataSource={useQuery('searchSalesBills')}>
    <column field="billNo" title="销货单号" />
    <column field="status" title="状态" />        // 枚举列自动彩色标签
    <button text="编辑" action={openDialog('SalesBillEdit', row)} />
    <button text="删除" action={useMutation('deleteSalesBill', row.id)} />
    <button text="复制" fold="true" action={...} />   // fold：折叠进"更多"菜单
  </table>
  <button text="新增销货单" action={openDialog('SalesBillEdit')} />
}

@title('销货单编辑')
dialog SalesBillEdit {                            // 新增/编辑类表单用 dialog（不进路由）
  <form submit={useMutation('saveSalesBill')}>
    <input field="billNo" label="销货单号" />
    <repeat field="items">                        // 明细行编辑（主子表）
      <input field="qty" label="数量" />
      <input field="price" label="单价" />
    </repeat>
    <button text="暂存" />
  </form>
  <button text="提交" action={useMutation('submitSalesBill')} />
}
```

### 4.1 绑定（唯一数据通道）

| 绑定 | 语义 |
|------|------|
| `useQuery('函数名')` | 取数 → hooks 状态喂组件 |
| `useMutation('函数名', args...)` | 提交 → 成功后自动 refetch 关联 query |
| `navigate('PageName', row.id)` | 页面导航（多页面路由） |
| `openDialog('DialogName', row)` | 打开弹窗 |

参数引用 `$route.id` 取路由参数；`row` 是表格行上下文。

### 4.2 内置组件

```
table / column / button / form / input / repeat / text / detail
管理端常用：tag(color) statistic(title,value) tabs > pane(title)
           checkbox / switch / radio(options="A,B") / avatar / badge(count) / card(title)
```

表单控件按字段类型自动升级：枚举 → Select（选项来自 enum）/ 日期 → DatePicker / 数字 → InputNumber。

### 4.3 表达式域（G2，dev/29）

```
<input field="amount" derive={qty * price} />        // 派生：纯函数表达式 → 计算 readOnly
<input field="goodsId" carryBy="getGoods">           // 带出：选中后调函数回填档案字段
  <input field="goodsName" />                        //   子字段 = 带出目标
</input>
```

`derive` 是纯函数：**禁止 IO 绑定**（useQuery/useMutation），叶子只能是兄弟字段/`row`/内核别名/实体/枚举；
`carryBy` 指向的函数返回实体必须含全部子字段。

## 5. 第三方库接入（dev/32 全流程）

```
① 扫描    dsl bundle-jar D:/x.jar -o <工程>/libs/x.json [--classes JSON,JSONObject]
          （坐标自动取 jar 内 pom.properties；产物人工收窄：精选类/修 alias/补模板）
② 声明    TDSL 顶层写 dependency java "g:a:v";（或 as ns 限定引用）
③ 使用    function 内直调 JSON.toJSONString(o) → check 校验成员、pom 自动注入坐标
          （npm 侧同理：dependency npm "pkg" import { Pie } → 页面直用 <Pie />，import 语句自动生成）
```

同名类撞 alias（fastjson vs jackson 都有 `JSON`）→ 报 D-dep-4，二选一消解：
改产物 JSON 的 `alias` 字段，或 `dependency java "..." as ns` 后用 `ns.JSON` 限定引用。
