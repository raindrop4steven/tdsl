# 29_系统设计-G2-前端表达式域（功能点清单 + 通道）

> <rv-add>2026-09。定位：把前端"功能点"枚举出来、每个功能点一个声明式插槽——语言面停止增长（derive/carry/validate/role/action 六通道），复杂纯计算与 IO 一律落 logic（后端承受）。
> 设计原则：**前端 = 纯函数面（函数(state)→视图），无变量/无语句/无 IO**；语境变量（row/initial/table 勾选集）按声明位置由编译器提供。</rv-add>

---

## 1. 设计原则（定案）

- **前端只写“意图”，不写语句**：derive 是一个纯函数表达式（无 const/let、无 if/循环、无三元）；依赖由编译器静态追出（React useMemo + antd Form deps）
- **IO 只经 binding**：useMutation/useQuery 的目标必须是后端 logic；derive 内禁 IO 调用
- **3 没有 / 2 有**：没变量、没语句、没 IO；有上下文只读值 + 目录纯函数成员（frontend:true 面）
- **谱系与 React 生态同构**：antd Form compute / React reactive 模型——LLM 做 rule 很自然

## 3. 语法通道（本轮四件套）

```tdsl
<form submit={useMutation('savePurchaseBill')}>
  <input field="goodsId" label="商品" carryBy="Goods.get">
    <input field="goodsName" label="商品名称" />      <!-- carry 目标字段块（后端取档后带出）-->
    <input field="spec" label="规格型号" />
  </input>
  <input field="qty" label="数量" required="true" min="1" max="99999" />
  <input field="price" label="单价" />
  <input field="amount" label="金额" derive={qty * price} />
  <input field="status" label="状态" required="false" />    <!-- 页面级覆盖实体必填推断 -->
  <input field="keyword" role="search" />               <!-- 主查询参数（显式）; 无 role = 旧宽容 -->
</form>
<!-- 弹窗内的提交（G5）：动作缺参由 initial.<param> 供给，LLM 不手写 -->
<button text="提交" action={useMutation('submitPurchaseBill')} />
```

- **derive 语义**：字段状态名 = 表单上下文（同 form 的 input/repeat 下的字段名）；纯函数（无语句/IO）；codegen React `computed`/useMemo；依赖集 = 表达式中的字段名
- **carryBy 语义**：属性值 = 带副档后端 logic 名（必须被 interface 暴露）；input children = 带出目标字段集合；载入的有效 payload = logic 返回实体上同名字段
- **校验属性**：required(覆盖实体推断)/min/max/pattern；typecheck 只做类型字面量宽松校验
- **role=search**：显式接线（与旧"名称匹配参数"宽松接线共存）

## 4. codegen/typecheck 职责边界

| 层 | 职责 |
|----|------|
| parser | 属性值是表达式/字符串照旧通用语法制造；**新语义即新属性**（derive/carryBy/required/min/max/role），无需新关键字 |
| typecheck | ① derive：表达式仅可引用同域字段/上下文（row/initial）；禁 useMutation；② carryBy：logic 存在+端点暴露+返回实体包含带出字段；③ 校验属性字面量类型 |
| codegen-react | derive→计算态;carryBy→onChange 拉档+带出填回；校验属性→提交拦截（合并实体推断）；role=search→主查询实参批量接线 |
| codegen-java | 无感（这是前端-only 语义；后端回避） |
