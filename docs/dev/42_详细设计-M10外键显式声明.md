## 1. 词法（parser.ts）

### 1.1 注解 token 流

现有：`@` → `expectIdent()` 得注解名四种（pk/nullable/unique/未知报错）。
新增对 `ref` 分支的带参解析（复用现有 lexer token：`(`、`)`、`,`、`:`、String 字面量、Ident）：

```ts
// parseEntity 内注解循环（约 L383）扩展：
else if (ann === 'ref') {
  this.expect('(');
  const short = this.expectIdent();                 // 实体短名或限定名（ds.Ent）
  let display = 'name';                              // 缺省，typecheck 兜底校验
  if (this.peek().value === ',') { this.next(); this.expectIdent(); /* 'display' */ this.expect(':'); display = this.expectString().value; }
  this.expect(')');
  prop.ref = { entityPath: short, display };          // link 阶段覆写为 nodePath
}
```

细则：
- 受限文法：仅 `display` 一个 KV；非法内部结构直接 `fail()`（解析期即报错，行列来自 expect* 抛点）。
- `resolveTypeRef(table, path, ds.name)` 直接复用（短名→同数据源优先→全局限定），绑定到 `entityPath`。

### 1.2 linkApp（新增第三段）

```ts
// M10 @ref 绑定：实体属性 ref 短名 → nodePath（与类型引用同 ctxDs 优先）
for (const ds of app.datasources) {
  for (const ent of ds.entities) {
    for (const p of ent.properties) {
      if (p.ref) p.ref.entityPath = resolveTypeRef(table, p.ref.entityPath, ds.name);
    }
  }
}
```

失败行为：抛 `TdslSyntaxError("cannot resolve entity-ref '<短名>'", 行, 列)`（ref 所在属性行）。

## 2. typecheck（第七类诊断 FK-REF）

| 码 | 等级 | 触发 | message（反例文案） | suggestion |
|----|------|------|---------------------|-----------|
| `FK-REF-ENTITY` | error | entityPath 非 Entity 引用 | `@ref 目标 '<path>' 不是实体` | `'应引用 entity 声明'` |
| `FK-REF-DISPLAY` | error | display 字段缺失或非 String | `@ref 实体 '<ent>' 的显示字段 '<f>' 不存在或不是 String` | `可用的字符串字段: ...` |
| `FK-REF-NO-QUERY` | warning | 目标实体不存在无参/全可参的 query 逻辑 | `@ref 实体 '<ent>' 缺少查询逻辑，前端下拉缺数据源` | `'补一个 queryXxx(): List<X>'` |

- nodePath + 行/列：Diagnostic path 用属性 nodePath（`app.datasources.yudaoDS.entities.CrmClue`），line/col 取 prop 的 BaseNode.line/col；
- R2 引入**属性查找辅助**：`entPropOf(ent, name)`——display 字段不存在，`xx` 属性名精确匹配，null → FK-REF-DISPLAY；
- R3 判定复用 codegen 同款 `apiFnOf` 逻辑（query 前缀 + List 泛型解包）抽公共函数放 `@tdsl/core`? **不**——复制一份轻实现于 typecheck（避免 core→codegen-react 引入逆向依赖；codegen 已 import core 单向）。
- slot 位锚：诊断遍历 `check()` 定序表中「实体与查询链」层内新增 `ref` 子遍历（实数据源 → 实体 → 属性，遍历属性时一并校验 ref）。
