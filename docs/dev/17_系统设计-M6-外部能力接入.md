# 17 系统设计：M6 —— 外部能力接入（service / component 主航道）

> 关联：`docs/dev/14_路线规划-NASL对标与前后端能力.md` §6（外部能力接入设计）、`10_设计/设计总览` §4（接口/页面）
> 状态：**阶段二（系统设计）** — 待用户 Gate 确认
> 定位：把"调用第三方后端能力（Dubbo/Jar SDK/HTTP）+ 引入第三方前端组件（npm）"做成 DSL 一等公民，
> TDSL 声明 `service`/`component`，codegen 生成真实的注入/装配/import 代码。

---

## 1. 目标与验收

### 1.1 现状

- **后端**：只能调用本 app 的实体方法（`X.all`/`get`/`where`/`save`/`delete`）与本地逻辑。无法调用 Dubbo 服务、本地 Jar SDK、外部 HTTP 服务。
- **前端**：ViewElement 只支持内置组件类型（table/column/button/form/input/repeat/text/detail）。无法引入第三方 npm 组件。

### 1.2 达成什么

1. **`service` 声明**：TDSL 描述外部后端能力（dubbo/bean/http 三种），logic 里像调本地方法一样调用，codegen 生成注入代码。
2. **`component` 声明**：TDSL 注册 npm 前端组件，ViewElement 引用它并参与数据绑定。
3. 与业务逻辑同文（声明式）、类型安全（typecheck 校验）、可生成（确定性 codegen）。

### 1.3 验收标准

- [ ] `service` 三种 kind（dubbo/bean/http）parse + typecheck + codegen 通过。
- [ ] codegen-java 生成 `@DubboReference`（dubbo）/ `@Autowired`（bean，含 pom 依赖）/ `@FeignClient`（http）注入。
- [ ] `component` 注册 parse + typecheck + codegen-react import + ViewElement 引用通过。
- [ ] 单测覆盖 service/component 全链路。
- [ ] 不回归 M1/M4 已有能力。

## 2. TDSL 书写面

### 2.1 后端 service 声明

```ts
// ---- 调用 Dubbo 服务 ----
@service(kind = 'dubbo', group = 'order-center', version = '1.0.0')
service UserService {
  getUser(id: Integer): UserDto;
  listUsers(ids: List<Integer>): List<UserDto>;
}

// ---- 调用本地 Jar SDK / Spring Bean ----
@service(kind = 'bean', bean = 'orderSdk', jar = 'com.example:order-sdk:1.0')
service OrderSdk {
  createOrder(input: OrderInput): OrderResult;
}

// ---- 调用 HTTP/REST 服务 ----
@service(kind = 'http', baseUrl = 'http://erp-center', timeout = 3000)
service ErpApi {
  GET '/api/orders/{id}' -> getOrder(id: Integer): OrderDto;
}

// ---- logic 里直接调用，与本地方法无差别 ----
@export
logic createOrderAndNotify(input: OrderInput): Order {
  order := createOrder(input);
  user := userService.getUser(order.customerId);   // Dubbo
  erpApi.postOrder(order);                          // HTTP
  return order;
}
```

### 2.2 前端 component 注册

```ts
// ---- 注册第三方组件 ----
component ECharts {
  pkg: 'echarts-for-react';                     // npm 包名 → import
  defaultProps: { option: Json; style: Json };  // props 契约
  events: ['onClick'];                          // 事件
}

// ---- 页面里作为 ViewElement 使用 ----
page OrderReport {
  <ECharts option={computeChartOption(orderStat)} dataSource={useQuery('orderStat')} />
}
```

## 3. IR 变更（core）

### 3.1 ServiceNode

```ts
interface ServiceNode extends BaseNode {
  kind: 'Service';
  name: string;
  kind_: 'dubbo' | 'bean' | 'http';   // 服务类型
  // dubbo: group/version；bean: bean 名 + jar 坐标；http: baseUrl
  config: Record<string, string>;
  operations: ServiceOperationNode[];
}

interface ServiceOperationNode extends BaseNode {
  kind: 'ServiceOperation';
  name: string;               // 方法名（http 由 path 派生）
  params: ParamNode[];
  returns: ReturnNode[];
  // http 特有
  method?: 'GET' | 'POST' | 'PUT' | 'DELETE';
  path?: string;
}
```

- `AppNode.services: ServiceNode[]` 新增。
- `AnyNode` 判别联合新增 `ServiceNode | ServiceOperationNode`。

### 3.2 ComponentNode

```ts
interface ComponentNode extends BaseNode {
  kind: 'Component';
  name: string;                 // 组件名（ViewElement.type 引用）
  pkg: string;                  // npm 包名
  defaultProps: string[];       // props 字段名（类型由书写面推导，简化先存字段名）
  events: string[];             // 事件名
}
```

- `AppNode.components: ComponentNode[]` 新增。
- `AnyNode` 判别联合新增 `ComponentNode`。

### 3.3 命名空间

- `service` / `component` 短名在 **app 全局**（与 structure/enum/logic 同级，link 时查重）。
- logic 内 `userService` / `erpApi` 是**局部变量**（变量名 = service 短名小驼峰），
  codegen 在 Service 类里注入字段，方法体内直接用变量名调用。

## 4. parser 变更

### 4.1 `service` 关键字

```
@service(kind = 'dubbo', group = 'order-center', version = '1.0.0')
service UserService {
  getUser(id: Integer): UserDto;
  listUsers(ids: List<Integer>): List<UserDto>;
}
```

- `@service(...)` 注解解析配置（kind/group/version/bean/jar/baseUrl/timeout）。
- `service Name { operations }`：操作体与 logic 签名一致（param + return），http 形态带 method + path。
- 顶层 `service` 关键字分支。

### 4.2 `component` 关键字

```
component ECharts {
  pkg: 'echarts-for-react';
  defaultProps: { option: Json; style: Json };
  events: ['onClick'];
}
```

- `component Name { pkg: 'x'; defaultProps: {...}; events: [...] }`。
- `defaultProps` 里的字段名提取（`option`/`style`）；类型后续推导（简化先存字段名）。
- 顶层 `component` 关键字分支。

### 4.3 link

- `service` 短名 → 全局符号表（`app.services.<name>`），与其他全局概念查重。
- logic 里 `userService.getUser(...)`：`userService` 是 service 短名的小驼峰变量（`name.charAt(0).toLowerCase()+slice(1)`），
  typecheck/codegen 识别为 service 调用。

---

## 5. typecheck 变更

- Service 校验：`kind` 合法（dubbo/bean/http）；操作签名可解析（参数/返回类型 resolve）。
- Component 校验：`pkg` 非空；events 数组元素为字符串。
- logic 内 service 调用：接收者（小驼峰变量名）能映射到已声明 service → 校验操作存在、参数/返回类型。
- 未知 service 变量调用 → 报错。

---

## 6. codegen-java 变更（service 注入）

### 6.1 生成策略

Service 类生成时，logic 若引用了外部 service → 注入对应字段：

| service kind | 注入 | pom 依赖 |
|--------------|------|----------|
| `dubbo` | `@DubboReference(group=..., version=...) private UserService userService;` | `org.apache.dubbo:dubbo-spring-boot-starter` |
| `bean` | `@Autowired private OrderSdk orderSdk;` | `com.example:order-sdk:1.0`（`jar` 坐标） |
| `http` | `@FeignClient(name="erp-center", url="http://erp-center") interface ErpApi {...}` | `org.springframework.cloud:spring-cloud-starter-openfeign` |

- 需要为新 service 接口生成 **Java 接口文件**（当前工程里没有该接口）：
  - dubbo：生成 `interface UserService { UserDto getUser(Long id); ... }`（无实现，消费方接口）。
  - bean：生成 `interface OrderSdk {...}`（若 Jar SDK 未提供，则声明式接口；若提供则直接依赖 + 不生成）。
  - http：生成 `@FeignClient` 接口（`@GetMapping`/`@PostMapping` 方法）。
- 引用收集：`collectUsedServices(logic)` → 从调用 `userService.xxx(...)` 识别 service 变量 → 注入对应字段 + import。
- 方法体内调用 `userService.getUser(id)` → 直接生成（变量名已注入）。

### 6.2 Service 调用代码生成

- `userService.getUser(id)` 在 genExpr 的 Call 分支：接收者 Ident 是已注册 service 变量 → 原样生成 `userService.getUser(id)`（注入字段已声明）。
- `erpApi.postOrder(order)` → `erpApi.postOrder(order)`（Feign 方法）。

## 7. codegen-react 变更（component 引入）

- `component ECharts { pkg: 'echarts-for-react' }` → 页面组件顶部生成 `import ECharts from 'echarts-for-react';`。
- ViewElement 的 `type` 若命中已注册 component → 生成 `<ECharts {...props} />`：
  - `dataSource={useQuery(...)}` → 查询数据作为 props 传入（`data={q.data}`）。
  - `option={expr}` → `option={genExpr(expr)}`。
  - `events` → 事件回调绑定。
- 内置组件与第三方组件同构（`genElement` 分发时先查 component 注册表，未命中再走内置分支）。
- `package.json` 依赖：注册的 component `pkg` → `dependencies` 加 `"echarts-for-react": "*"`。
