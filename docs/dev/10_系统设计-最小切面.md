## 1. 仓库布局（npm workspaces）

```
tsc/
├── package.json              # workspaces: ["packages/*"]（生成产物独立构建，不进 workspace）
├── tsconfig.base.json        # strict
├── packages/
│   ├── core/                 # Typed AST 类型 + 节点模型（无运行时依赖）
│   ├── parser/               # TDSL(TS 书写面子集) → Typed AST
│   ├── typecheck/            # 最小版：引用 resolve 绑定 + 基本赋值兼容
│   ├── codegen-java/         # App → Spring Boot 工程文件 (GeneratedFile[])
│   └── codegen-react/        # App → Vite+React 工程文件 (GeneratedFile[])
└── examples/
    └── todo-app/
        ├── todo.tdsl         # 输入（LLM 书写面的最小样本）
        ├── scripts/slice.ts  # 闭环驱动：parse→typecheck→双端 codegen→写盘→触发 build
        └── generated/        # java/ + react/ 生成产物（gitignore）
```

依赖方向：`core` ← `parser`/`typecheck` ← `codegen-*` ← `examples/todo-app`

## 2. 数据流（验证闭环）

```
todo.tdsl ──parser.parse──▶ AppNode ──typecheck.check──▶ { ok, diagnostics }
                                    │ ok
                                    ├─codegen-java.generate──▶ generated/java/ ──mvn compile──▶ exit 0
                                    └─codegen-react.generate─▶ generated/react/ ──vite build──▶ exit 0
```

- parser/typecheck 失败 → 打印诊断，退出非零，**不生成**。
- 两端产物各自 build 通过即验收；语义一致性由**同一份 AST** 保证。

## 3. 模块设计

### 3.1 `core` —— Typed AST

按 `30_详细设计` §1-3 裁剪，最小节点集：

- `BaseNode { kind, id }`；`Annotation`
- `AppNode` 聚合 `datasources/structures/enums/logics`（views 本期预留空数组，不定义 ViewNode）
- `EntityNode/EntityPropertyNode`（type: TypeRef, primary/nullable）
- `StructureNode/StructurePropertyNode`、`EnumNode/EnumItemNode`
- `LogicNode { name, params, returns, body }`、`ParamNode/ReturnNode`
- `TypeRef`：`primitive`（7 内置）/ `reference`（nodePath 字符串）/ `generic List<T>` / `db`
- 最小 `Expr`：`Ident/Member/Call/New/Literal(Bool|Numeric|String|Null)/Binary(===,!==,&&,||,+,<,<=)/Group`
- 最小 `Statement`：`VarDecl/Assign/Return/If/ForEach/CallStmt`
- 工具：`createNode`（生成 uuid）、`nodePathOf(node)` / `resolve(app, path)`

> 取舍：`kind` 由判别联合字面量推导（D2）；引用用 nodePath 字符串（D3）。

### 3.2 `parser` —— TDSL 书写面子集

手写递归下降，支持：

```
@datasource('defaultDS')
entity Todo {
  id: Integer @pk;
  title: String;
  done: Boolean;
}

struct TodoInput { title: String; done: Boolean; }

enum Priority { LOW, HIGH }          // 本期仅验证，demo 可不引用

@export
logic findTodos(): List<Todo> {
  result := new List<Todo>();
  for (todo in Todo.all) {
    if (todo.done === false) { result.add(todo); }
  }
  return result;
}
```

语法糖归一：
- `@pk` → `EntityPropertyNode.primary = true`
- `Integer`/`String`/`Decimal(10,2)` → TypeRef（primitive/db）
- `:=` → `Assign`；`new List<T>()` → `NewList`；`Todo.all` → 符号引用成员
- `for (x in y)` → `ForEach`；`x.y()` 方法调用 → `Call(Member)`

错误：`SyntaxError { line, col, message }`，parser 内部维护行列游标。

### 3.3 `typecheck` —— 最小版

- `bind`：构建 SymbolTable（nodePath → 节点），`resolve` 校验所有 reference，悬空 → Diagnostic
- `assignable(from, to)`：primitive 匹配 + `Integer→Decimal` 隐式 + `List<T>` 参数化匹配
- 返回 `{ ok, diagnostics: Diagnostic[] }`，`Diagnostic { path, line?, col?, message, severity }`

> 不做：类型推导、泛型统一、成员方法签名校验（P1）。

### 3.4 `codegen-java` —— 完整 Spring Boot 工程

`generate(app): GeneratedFile[]`，产出（路径相对生成根）：

```
pom.xml                        # Java 17, spring-boot-starter-web + data-jpa, junit
src/main/java/com/todo/TodoApplication.java        # @SpringBootApplication
src/main/java/com/todo/entity/Todo.java            # @Entity + @Table + @Id/@Column + @NotNull
src/main/java/com/todo/service/TodoService.java    # @Service, findTodos(): List<Todo>
src/main/resources/application.yml
```

- 类型映射：`Integer→long`、`Decimal→BigDecimal`、`Date→LocalDate`、`DateTime→ZonedDateTime`、`Boolean→boolean`、`String→String`、`List<T>→java.util.List<T>`
- `Logic.body` 本期生成**最小语义等价体**（findTodos 生成遍历+条件过滤的 Java 代码或最小桩），保证 `mvn compile` 通过
- 每节点 `never` 穷尽 switch

### 3.5 `codegen-react` —— 完整 Vite 工程

`generate(app): GeneratedFile[]`，产出：

```
package.json                   # react 18 + vite 5 + typescript + @vitejs/plugin-react
vite.config.ts
tsconfig.json
index.html
src/main.tsx
src/types/todo.ts              # Entity → TS interface（Boolean→boolean, Integer→number, Decimal→number）
src/App.tsx                    # View 组件：渲染 Todo 列表（模拟 fetch，build 只查类型）
```

- 本期不解析 View/JSX：`App.tsx` 由生成器按固定模板产出 + 注入 Todo 类型字段
- `never` 穷尽 switch 处理 Entity/TypeRef

## 4. 错误处理

| 层 | 错误 | 表现 |
|----|------|------|
| parser | 语法错误 | `SyntaxError{line,col,message}`，slice.ts 打印后 exit 1 |
| typecheck | 悬空引用/类型不兼容 | `Diagnostic[]` 打印后 exit 1 |
| codegen | 未处理节点 | `never` 收窄 → TS 编译失败（强制补全） |
| build | mvn/vite 失败 | slice.ts 捕获子进程非零退出码，汇总报告 |

## 5. 测试策略

- **单测（vitest）**：
  - parser：合法输入 → AST 断言；非法输入 → 行列错误
  - typecheck：悬空引用、Integer→Decimal 隐式、List<T> 匹配
  - codegen：快照测试（生成文件内容确定性）
- **集成（slice.ts）**：`npm run slice` 一键跑完 parse→check→gen→双端 build，全部 exit 0

## 6. 与项目级设计的差异（有意裁剪）

| 项目级设计 | 切面实现 | 说明 |
|-----------|---------|------|
| schema 包 / JSON AST | 不做 | P1+，LLM 直出 JSON 才需要 |
| View/JSX parser | 不做 | React 端用固定模板 + 注入 |
| Interface/Controller | 不做 | P1 |
| 完整 typecheck | 最小绑定+兼容 | P1 |
