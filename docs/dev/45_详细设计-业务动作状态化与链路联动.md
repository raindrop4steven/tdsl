## 1. codegen-react 改造（主）

### 1.1 枚举成员字面量化

```ts
/** 枚举成员引用 → 字符串字面量（实体列按枚举名存储，前端值即名字符串）；非枚举成员返回 null */
function enumMemberLiteralOf(app: AppNode, e: Expr): string | null {
  if (e.kind !== 'Member') return null;
  const obj = e.obj;
  if (obj.kind !== 'Ident') return null;
  if (!app.enums.some((en) => en.name === obj.name)) return null;
  return `'${e.prop}'`;
}
```

挂点：`exprToJs` 的 `case 'Member'` 首行调用；命中则返回字面量，否则原有 `obj.prop` 逻辑（derive 同步受益）。

### 1.2 按钮 `visible` / `disabled`

`genButton` 内前置计算（5 个返回点统一接线）：

```ts
const visExpr  = el.props['visible']  as Expr | undefined;
const disExpr  = el.props['disabled'] as Expr | undefined;
const visCond  = visExpr ? exprToJs(app, visExpr, undefined) : null;   // row 上下文，原样引用 row
const disAttr  = disExpr ? ` disabled={${exprToJs(app, disExpr, undefined)}}` : '';
```

- 各分支 `<Button${disAttr} ...>`；`Popconfirm` 分支把 `disAttr` 挂内层 `<Button>`；
- 末尾统一包裹：`visCond ? `{${visCond} && (${jsx})}` : jsx`；
- **折叠计划不变**：`foldRowButtonPlan` 仍按静态按钮数（dev/44 §3.2）。

### 1.3 明细合计 `<summary>`

`genForm` 末尾（`repeatEls` 之后）新增：

```ts
const summaryEls = el.children.filter((c) => c.type === 'summary').map((s) => {
  const field = String(s.props.field ?? '');
  const itemStruct = repeatItemStructOfField(app, el, field);      // 复用 repeatItemStruct（按 field 找 repeat 元素）
  const label = String(s.props.label ?? '合计');
  const expr = s.props['expr'] as Expr | undefined;
  const of = s.props['of'] !== undefined ? String(s.props['of']) : null;
  const reduce = expr
    ? `(${field}.reduce((s, it) => s + (${summaryExprToJs(app, expr, itemStruct)}), 0)).toFixed(2)`
    : `(${field}.reduce((s, it) => s + Number(it.${of}), 0)).toFixed(2)`;
  return `  <div style={{ textAlign: 'right', marginTop: 8, fontWeight: 600 }}>${label}：{${reduce}}</div>`;
});
```

`summaryExprToJs(app, e, itemStruct)`：受限表达式编译，`Ident` → `it.<name>`（数值字段包 `Number(...)`），支持 `+ - * /` 与括号；其他形态原样透传（typecheck 宽松）。

### 1.4 详情只读子表（`<detail>` 内 `<repeat>`）

- 抽公共列定义：`genTable` 内 `colDefs` 计算提为 `columnDefsOf(app, rowEnt, columns, fieldPrefix)`，`genTable` 与 `genDetail` 共用（枚举 Tag / 外键名 / 原值三态一致）；
- `genDetail` 增加分支：

```ts
const reps = el.children.filter((c) => c.type === 'repeat').map((r) => {
  const field = String(r.props.field ?? 'items');
  const itemEnt = detailItemEntityOf(app, qBinding?.target, field);   // 详情返回结构体 → List<XxxItem> 实参实体
```

- import 收集：`collectAntdComponents` 中，`detail` 元素含 `repeat` 子元素时补 `Table`。

## 2. typecheck 改造（小）

| 码 | 等级 | 触发 | message |
|----|------|------|---------|
| `SUMMARY-TARGET` | error | `summary.field` 在同 form 内无同名 `repeat` | `summary 的 field '<f>' 未匹配到同表单的 repeat` |

## 3. yudao TDSL 逻辑设计

### 3.1 共享库存入口（20-stock.tdsl）

```tdsl
// 库存增减 + 流水（审批/反审批共用；不足时抛业务错误）
function applyStock(productId: Integer, warehouseId: Integer, delta: Decimal,
                    bizType: StockRecordBizType, bizId: Integer, bizNo: String): Boolean {
  const rows = Stock.where(productId = productId, warehouseId = warehouseId);
  const s = new Stock();                      // 无则建行
  if (rows.count > 0) { const s = rows[0]; }  // 有则取首行
  const next = s.count + delta;
  if (next < 0) { throw '库存不足'; }         // 出库前置校验（反审批回退同理）
  s.productId = productId; s.warehouseId = warehouseId; s.count = next; s.save();
  const rec = new StockRecord();              // 流水快照
  rec.productId = productId; rec.warehouseId = warehouseId; rec.count = delta;
  rec.totalCount = next; rec.bizType = bizType; rec.bizId = bizId; rec.bizNo = bizNo;
  rec.save();
  return true;
}
```

### 3.2 联动接线

| logic | 追加逻辑 |
|-------|----------|
| `auditErpPurchaseIn` | `for it of PurchaseInItem.where(inId = id)`：`applyStock(it.productId, it.warehouseId, it.count, PURCHASE_IN, id, b.no)`；`orderItem = PurchaseOrderItem.get(it.orderItemId)` → `orderItem.inCount += it.count`；全部入库 → `PurchaseOrder.status = AUDITED` |
| `deauditErpPurchaseIn` | 反向：`applyStock(..., -count, PURCHASE_IN_CANCEL, ...)`；`inCount -= count`；订单回 `UNAUDIT` |
| `auditErpPurchaseReturn` | `applyStock(..., -count, PURCHASE_RETURN, ...)` |
| `auditErpSaleOut` | `applyStock(..., -count, SALE_OUT, ...)`（不足即 throw 回滚）；`SaleOrderItem.outCount += count`；全出库 → `SaleOrder.status = AUDITED` |
| `deauditErpSaleOut` | `applyStock(..., +count, SALE_OUT_CANCEL, ...)`；`outCount -= count` |
| `auditErpSaleReturn` | `applyStock(..., +count, SALE_RETURN, ...)` |
| `auditErpPurchasePayment` | 逐 `FinancePaymentItem` → 按 `bizNo` 找 `PurchaseIn`：`paid = (in.paymentPrice ?? 0) + item.paymentPrice` 回写 |
| `auditErpSaleReceipt` | 逐 `FinanceReceiptItem` → `SaleOut.receiptPrice += item.receiptPrice` |
| `deauditErpPurchasePayment` / `deauditErpSaleReceipt` | 反向回退 |

> 幂等：状态机前置校验（仅 UNAUDIT 可审批）已保证；反审批同理由 AUDITED 进入，不会重复扣减。

### 3.3 详情聚合（仅 2 个单据）

```tdsl
struct PurchaseInDetail { in: PurchaseIn; items: List<PurchaseInItem>; }
@export function getErpPurchaseInDetail(id: Integer): PurchaseInDetail {
  const d = new PurchaseInDetail();
  d.in = PurchaseIn.get(id);
  d.items = PurchaseInItem.where(inId = id);
  return d;
}

struct SaleOutDetail { out: SaleOut; items: List<SaleOutItem>; }
@export function getErpSaleOutDetail(id: Integer): SaleOutDetail { ... }
```

- 端点：`GET '/api/erp/purchase-ins/{id}/detail' -> getErpPurchaseInDetail`、`GET '/api/erp/sale-outs/{id}/detail' -> getErpSaleOutDetail`；
- 页面：详情抽屉改查 detail 逻辑，`<text field="in.no">` + `<repeat field="items">` 子表（`erpPurchaseInDetail` / `erpSaleOutDetail`）。
