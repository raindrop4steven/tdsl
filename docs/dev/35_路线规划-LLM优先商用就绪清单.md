## 编译器相关（优先做，P0）

1. **诊断全量结构化**：Diagnostic 加 `code` + `suggestion` 字段；**全量齐报不截断**，按依赖序排序、级联检测分组（根因在前）——"都给，然后分层"；eval 按 code 统计修复成功率
2. **表达式层类型核对**：赋值/传参、logic 互调 arity、成员访问、return 核对、nullable——无推导的核对（TDSL 显式类型），knownVars 扩成变量作用域；宽松放行只做兜底
3. **业务表达力补全**（language 面全链路，六步闭环）：try/throw（A1）→ join/事务边界（M5）→ G2 前端表达式域

出牌/取用不做进编译器：报错分类分层交付给所有调用方即止（P0-1 的 code/排序/分组已覆盖），LLM 怎么修是它自己的事。
