## 测试层级
- **单元测试（50_测试用例）**：parser、typecheck、codegen 各子模块。
  - parser：合法/非法 TDSL 输入 → AST / 报错。
  - **round-trip**：`deserialize(serialize(ast)) === ast`。
  - typecheck：赋值兼容、隐式转换、悬空引用诊断。
  - codegen：快照测试（snapshot）保证 React/Java 输出确定性。
- **集成测试（60_集成测试）**：TDSL → AST → typecheck → React/Java，端到端编译产物可 build。
